###  Цель работы
Изучение средств мониторинга для сбора и обработки телеметрии приложений и настройка системы, в которой данные метрик, журналов и трассировок собираются для микросервисного приложения на языке Python с использованием OpenTelemetry и Jaeger.


###  Код приложений и конфигурационных файлов
Все файлы размещены в каталоге `task1/`:
- `app.py` — веб-приложение на Flask с инструментированием OpenTelemetry и ручным созданием спана.
- `requirements.txt` — список зависимостей Python.
- `Dockerfile` — инструкции для сборки Docker-образа приложения.
- `docker-compose.yml` — конфигурация оркестрации сервисов (`jaeger` и `flask-otel-app`).
